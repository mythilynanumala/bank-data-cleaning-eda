# Task 02: Data Cleaning and Exploratory Data Analysis

## Project Overview
This project explores a bank marketing dataset using Python.

## Objectives
- Inspect the dataset.
- Check missing values and duplicate records.
- Explore numerical and categorical variables.
- Visualize customer age distributions.
- Explore relationships between customer characteristics
  and term deposit subscriptions.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Visualizations
- Bank Customer Age Distribution
- Term Deposit Subscription Rate by Job
- Customer Age by Term Deposit Subscription

## Conclusion
This project demonstrates data cleaning, exploratory data
analysis, and data visualization using Python.
